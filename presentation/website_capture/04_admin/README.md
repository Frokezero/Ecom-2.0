# 04 ระบบแอดมิน

ใช้เซสชันภายในเครื่องสำหรับภาพระบบหลังบ้าน ครอบคลุมหน้าภาพรวม การขาย ร้านค้า การเงิน การช่วยเหลือ และความปลอดภัย

ภาพในโฟลเดอร์: **18 หน้า**

## 01. แดชบอร์ดแอดมิน

![แดชบอร์ดแอดมิน](01_dashboard.png)

**สิ่งที่แสดง:** ตัวเลขภาพรวมและงานที่ต้องติดตาม

**วิธีใช้งาน:** ดูยอดขาย จำนวนออเดอร์ งานรอดำเนินการ และใช้ทางลัดไปหน้าที่ต้องจัดการ

**ตำแหน่งหน้า:** `admin/index.php`

## 02. สินค้าของเว็บไซต์

![สินค้าของเว็บไซต์](02_products.png)

**สิ่งที่แสดง:** เพิ่ม แก้ไข และตรวจรายการสินค้าหลัก

**วิธีใช้งาน:** ค้นหาสินค้า เพิ่มหรือแก้ข้อมูล ราคา รูป หมวด และสถานะการเผยแพร่

**ตำแหน่งหน้า:** `admin/products.php`

## 03. โปรโมชันและคูปอง

![โปรโมชันและคูปอง](03_promotions.png)

**สิ่งที่แสดง:** แคมเปญส่วนลดและคูปอง

**วิธีใช้งาน:** สร้างหรือแก้คูปอง/โปรโมชัน ตั้งสิทธิ์และช่วงเวลา แล้วตรวจสถานะใช้งาน

**ตำแหน่งหน้า:** `admin/promotions.php`

## 04. โปรโมชัน MALL

![โปรโมชัน MALL](04_mall_promotions.png)

**สิ่งที่แสดง:** กิจกรรมส่งเสริมการขายระดับเว็บไซต์

**วิธีใช้งาน:** จัดการแคมเปญระดับ MALL และการนำเสนอโปรโมชันบนเว็บไซต์

**ตำแหน่งหน้า:** `admin/mall-promotions.php`

## 05. คำสั่งซื้อ

![คำสั่งซื้อ](05_orders.png)

**สิ่งที่แสดง:** รายการออเดอร์ทั้งหมดและตัวกรองสถานะ

**วิธีใช้งาน:** กรองออเดอร์ตามสถานะ เปิดรายละเอียด และติดตามขั้นตอนชำระ/จัดส่ง

**ตำแหน่งหน้า:** `admin/orders.php`

## 06. รายละเอียดออเดอร์

![รายละเอียดออเดอร์](06_order_detail.png)

**สิ่งที่แสดง:** ข้อมูลออเดอร์ การชำระเงิน และการจัดส่ง

**วิธีใช้งาน:** ตรวจรายการสินค้า ผู้รับ การชำระ และประวัติสถานะ ก่อนดำเนินการต่อ

**ตำแหน่งหน้า:** `admin/order-detail.php?id=24`

## 07. คืนสินค้าและคืนเงิน

![คืนสินค้าและคืนเงิน](07_returns.png)

**สิ่งที่แสดง:** รายการคำขอและสถานะการดำเนินการ

**วิธีใช้งาน:** เปิดคำขอคืนสินค้า ตรวจเหตุผลและหลักฐาน แล้วอัปเดตผลการพิจารณา

**ตำแหน่งหน้า:** `admin/returns.php`

## 08. ศูนย์ช่วยเหลือลูกค้า

![ศูนย์ช่วยเหลือลูกค้า](08_support.png)

**ตำแหน่งหน้า:** `admin/support.php`

## 09. คำขอผู้ขาย

![คำขอผู้ขาย](09_sellers.png)

## 13. รายงานสินค้า
